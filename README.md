# salary-app 资产分配记账

一个单文件的工资分配与收支记账 PWA。无需服务器、无账号，数据保存在浏览器本地。

## 访问

在线使用：<https://hukernel.github.io/salary-app/salary.html>

## 功能

- **四账户分配**：收入按比例自动分配到 日常生活 / 必须存储 / 备用金 / 理财，也可手动指定各账户的具体金额
- **账户转账**：四个账户之间自由划转，不影响收支统计
- **支出分类**：内置常用分类，支持自定义分类（可管理/删除）
- **图表**：年 / 月 / 日三档收支折线，分类构成环形图，点击查看明细
- **月度预算**：设置每月支出上限，进度条 + 超支提醒
- **环比**：月度小结显示与上月的收支对比
- **提醒**：每日记账提醒 / 发薪日提醒，支持系统通知和日历（.ics）导入
- **备份**：一键导出 / 导入 JSON 备份，换设备不丢数据

## 添加到手机主屏幕（推荐）

安装后无地址栏，像原生 App 一样使用，且支持离线：

- **iPhone**：Safari 打开上面链接 → 底部分享按钮 → 「添加到主屏幕」
- **Android**：Chrome 打开链接 → 菜单 → 「添加到主屏幕」/「安装应用」

> 数据保存在浏览器本地，卸载浏览器或清除站点数据会丢失，建议定期用「备份」功能导出 JSON 文件。
